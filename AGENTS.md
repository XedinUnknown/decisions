# Agent Instructions

[README.md](README.md) and [CONTRIBUTORS.md](CONTRIBUTORS.md) apply to agents too.

## Source of truth

- [docs/concept.md](docs/concept.md) is the product concept. It is a draft and records no decisions. Read it before exploring or proposing a change.
- Claims tagged `[U]` (unverified) or `[?]` (unknown) in the concept must not be built on. A change that depends on one either closes it first (as a spike) or names it as an explicit assumption.
- [docs/decisions/](docs/decisions/) holds accepted decisions (MADR). They override the concept where the two disagree; cite them by number.
- OpenSpec owns planning: `openspec/specs/` describes shipped behaviour, and `openspec/changes/` holds proposals. Project context for OpenSpec lives in [openspec/config.yaml](openspec/config.yaml).

## Open-source readiness

This repository may be open-sourced. Avoid depending on anything company-internal (private services, internal URLs, Confluence pages, proprietary data, internal names) unless it is unavoidable. Where it is unavoidable, keep it in isolated, replaceable places such as config, fixtures or a clearly marked pilot, so it can be removed without affecting the product. Examples, test data and docs should use generic or public material.

## OpenSpec skills

The `openspec-*` skills live in `.agents/skills/` and are linked from `.claude/skills/`. They are generated by `openspec init` and `openspec update`; regenerate them instead of editing them by hand.
